Start here.

This project is a role-based environmental sensor platform for the municipality of Lingen (Ems): a Python producer replays a public IoT dataset into Kafka, Spark Structured Streaming validates and scores it, Cassandra stores it, and a role-based web app plus a Grafana KPI deck put it in front of two audiences — city planners and infrastructure operators. Nineteen Docker containers, one docker compose up -d.

This documentation set explains how it's built and how to run, deploy, and maintain it. Pick a page below, or use the sidebar link on any page to come back here.
